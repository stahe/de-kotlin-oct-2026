    15. Anhänge

    15.1. Das DBMS MySQL mit Laragon

    Die Kapitel 10 und 11 dieses Dokuments verwenden das DBMS MySQL 8. Am einfachsten installieren Sie es unter Windows, indem Sie Laragon installieren, eine portable Entwicklungsumgebung, die MySQL, den grafischen Client HeidiSQL, ein vorkonfiguriertes Terminal, Apache und PHP enthält. Der Autor verwendet sie auch für seine PHP-Kurse.

    15.1.1. Installation

    Laragon kann von https://laragon.org heruntergeladen werden. Die Installation verläuft standardmäßig; Sie können den vorgeschlagenen Installationsordner verwenden ([C:\laragon]). Laragon stellt MySQL 8 bereit (die genaue Version hängt von der Laragon-Version ab), mit einem Administratorkonto [root], das kein Passwort hat, und einem Server, der auf dem lokalen Rechner auf Port 3306 lauscht. Diese Konfiguration setzen die Beispiele im Dokument voraus, in dem die JDBC-URL die folgende Form hat:

    1
    jdbc:mysql://localhost:3306/dbarticles

    mit dem Benutzernamen [root] und einem leeren Passwort. Wurde MySQL anders installiert, mit einem Passwort für [root], müssen Sie die Beispiele entsprechend anpassen ([.properties]-Dateien oder Konstanten am Anfang der Programme).

    Auf einem System ohne Laragon können Sie MySQL Community Server auch von https://dev.mysql.com/downloads/mysql/ installieren, oder dessen Open-Source-Abkömmling MariaDB. Die Beispiele wurden jedoch nur mit MySQL 8 getestet: Die Skripte in Kapitel 10 verwenden eine für MySQL 8 spezifische Kollation ([utf8mb4_0900_ai_ci]), und mit MariaDB müssten sie ebenso angepasst werden wie der JDBC-Treiber (MariaDB stellt einen eigenen bereit).

    15.1.2. MySQL starten und beenden

    Das Hauptfenster von Laragon enthält eine Schaltfläche „Start All“ , die die Server (Apache und MySQL) startet, und eine Schaltfläche „Stop“, die sie beendet. MySQL ist kein Windows-Dienst, der beim Systemstart läuft: Es läuft nur, wenn es über Laragon gestartet wurde, wodurch verhindert wird, dass es Ressourcen verbraucht, wenn es nicht benötigt wird. Über das Laragon-Menü (Rechtsklick im Fenster) können Sie außerdem nur MySQL starten und dessen Version auswählen.

    Wenn MySQL nicht läuft, scheitern die Programme der Kapitel 10 und 11 mit einer Ausnahme des JDBC-Treibers, die anzeigt, dass keine Verbindung hergestellt werden konnte ([CommunicationsException]: „Communications link failure“): Das ist im Fehlerfall das Erste, was Sie prüfen sollten.

    15.1.3. Der Kommandozeilenclient

    Die Schaltfläche Terminal von Laragon öffnet ein Terminal, in dem die Laragon-Befehle zugänglich sind, darunter der MySQL-Kommandozeilenclient ([mysql]). Um sich mit dem Server zu verbinden, verwenden Sie:

    1
    > mysql -u root

    Geben Sie anschließend die SQL-Befehle ein, jeweils mit einem Semikolon abgeschlossen ([show databases;], [use dbarticles;], [select * from articles;]), und [exit] zum Beenden. Der Client kann auch ein SQL-Skript ausführen, was Kapitel 10 tut, um seine Datenbanken zu erstellen:

    1
2
3
    > cd kotlin-oct-2026\10-jdbc\sql
> mysql -u root < dbarticles.sql
> mysql -u root < dbtaxes.sql

    Die Skripte erstellen ihre Datenbank bei jeder Ausführung vollständig neu: Sie können sie erneut ausführen, um nach Tests die Daten in den Ausgangszustand zurückzuversetzen.

    15.1.4. Der grafische Client HeidiSQL

    Die Schaltfläche Database von Laragon startet den grafischen Client HeidiSQL. Beim ersten Start bietet HeidiSQL eine Verbindungssitzung an, die bereits für den MySQL-Server von Laragon konfiguriert ist (Host [127.0.0.1], Benutzer [root], leeres Passwort, Port 3306); öffnen Sie sie einfach. Sie sehen:

    • links die Baumansicht der Datenbanken des Servers und ihrer Tabellen;
    • rechts Registerkarten mit der Struktur einer Tabelle, ihren Daten (die direkt bearbeitet werden können) und einem Feld zur Eingabe von SQL-Abfragen (die Registerkarte „Query“), die mit [F9] ausgeführt werden.

    Um mit einem Skript aus Kapitel 10 eine Datenbank zu erstellen, öffnen Sie das Skript (über das Menü „File“ mit dem Befehl zum Laden einer Datei: SQL) in einer Abfrage-Registerkarte und führen es dann aus ([F9]). Sie können eine Datenbank, einen Benutzer und Benutzerberechtigungen auch über die Menüs von HeidiSQL erstellen (Rechtsklick auf die Verbindung / „Create New“ / „Database“; Menü „Tools“ / „User Manager“), aber die SQL-Skripte haben den Vorteil, reproduzierbar und wiederholt ausführbar zu sein.

    IntelliJ IDEA kann sich ebenfalls über sein Fenster „Database“ mit einer Datenbank verbinden: Dort können Sie die Tabellen und ihre Daten ansehen und SQL-Abfragen ausführen, ohne die IDE zu verlassen.

    Die Kapitel 10 und 11 verwenden die folgenden Datenbanken, die sich alle auf dem lokalen MySQL-Server befinden:

    Erstellung

    Nach Abschluss der Tests kann eine Datenbank mit dem SQL-Befehl [drop database name;] gelöscht werden, im Client [mysql] oder in HeidiSQL.
