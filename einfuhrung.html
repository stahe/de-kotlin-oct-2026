    Dieses Dokument ist ein Produkt von Claude, der KI von Anthropic. Es ist die Kotlin-Fassung des Kurses „Die Sprache Java 25 anhand von Beispielen lernen“ (Oktober 2026), der seinerseits eine Portierung des Kurses „C# 14 lernen mit .NET 10“ (Oktober 2026) ist, einer Neufassung des Kurses „Die Sprache C#, Version 3.0, mit dem Framework .NET 3.5 lernen“, den Serge Tahé im Mai 2008 verfasst hat. Es behält Gliederung, Beispiele und roten Faden dieses Kurses bei und schreibt sie in das heutige Kotlin um:

    • Das Dokument verwendet Kotlin 2.4 (Version 2.4.20, September 2026) mit JDK 25, der neuesten Version mit Langzeitunterstützung (LTS) von Java. Kotlin ist eine Sprache für die Java Virtual Machine: Sie erzeugt denselben Zwischencode wie Java und nutzt direkt alle ihre Bibliotheken. Leser des Java-Kurses finden daher dieselben Klassen des JDK (Dateien, Netzwerk, Threads, Datumsangaben usw.) und dieselben Frameworks (JUnit, Spring, Jackson, Hibernate, Spring Boot) wieder, nur aus einer anderen Sprache heraus verwendet;
    • wo sich die beiden Sprachen unterscheiden, geht dieses Dokument über eine bloße Übersetzung hinaus. Kotlin bietet eigene Lösungen für Probleme, die Java anders behandelt: die ins Typsystem integrierte Null-Sicherheit, Properties, Datenklassen, Erweiterungsfunktionen, Operatorüberladung, funktionale Typen, Standardwerte für Parameter und benannte Argumente sowie der Ausdruck [when]. Umgekehrt kennt Kotlin weder geprüfte Ausnahmen noch [static]-Member. Diese Unterschiede werden ausführlich dargestellt, oft im Vergleich von Kotlin-Code mit Java-Code;
    • das Kapitel über asynchrone Programmierung hat einen anderen Charakter: Während Java [CompletableFuture]-Klassen und virtuelle Threads verwendet, bietet Kotlin Coroutinen mit [suspend]-Funktionen, den Konstrukten [launch] und [async] sowie strukturierter Nebenläufigkeit. Das ist Kotlins Antwort auf das [async] / [await] von C# aus dem ursprünglichen Kurs;
    • die Bibliotheken sind die auf der JVM derzeit gebräuchlichen: [JUnit 6] und [kotlin.test] für Tests, [Spring Framework 7] für Dependency Injection, [Jackson 3] für JSON, [kotlinx.coroutines] für Coroutinen, der Treiber [MySQL Connector/J] für JDBC, [Hibernate 7] für die objektrelationale Abbildung und [Spring Boot 4] für Webservices; die Projekte werden mit [Gradle] erstellt, dessen Skripte selbst in Kotlin geschrieben sind.

    Dieses Dokument ist kein umfassender Kurs. Wie die Unterlagen, aus denen es hervorgegangen ist, richtet es sich an Leser, die bereits programmieren können und die Grundlagen von Kotlin erlernen möchten. Es arbeitet mit Beispielen: mehr als zweihundert Programme (mehr als dreihundert Kotlin-Dateien), die meisten davon kurz und Zeile für Zeile kommentiert.

    1.1. Kotlin von 2011 bis 2026

    Kotlin wurde im Juli 2011 vom Unternehmen JetBrains vorgestellt, dem Hersteller der IDE IntelliJ IDEA. Es suchte eine Sprache, die für die Entwicklung der eigenen Werkzeuge prägnanter und sicherer als Java und dennoch mit ihm kompatibel war: Ein Kotlin-Programm wird in Bytecode übersetzt, von der Java Virtual Machine (der JVM) ausgeführt und kann Java-Code aufrufen sowie von ihm aufgerufen werden. Der Name stammt von einer Insel im Finnischen Meerbusen nahe Sankt Petersburg, wo das Team arbeitete, das die Sprache entworfen hat.

    Wichtige Meilensteine:

    • 2016: Kotlin 1.0, die erste stabile Version, mit der zugehörigen Kompatibilitätszusage;
    • 2017: Google kündigte die offizielle Unterstützung von Kotlin für die Entwicklung von Android-Apps an; 2019 wurde Android „Kotlin first“: Kotlin ist die empfohlene Sprache für neue Android-Apps;
    • 2018: Kotlin 1.3, das Coroutinen stabilisierte, Kotlins Antwort auf die asynchrone Programmierung (Kapitel 9);
    • Die Sprache wird von JetBrains entwickelt; die Kotlin Foundation, 2017 von JetBrains und Google gegründet, überwacht ihre Weiterentwicklung, wobei jeder Schritt öffentlichen Vorschlägen unterliegt (den „KEEP“, Kotlin Evolution and Enhancement Process);
    • 2024: Kotlin 2.0 mit einem neuen Compiler namens K2, der schneller ist und Typen im Code besser nachverfolgt (Smart Casts);
    • Kotlin zielt auch auf andere Plattformen als die JVM: JavaScript, WebAssembly und nativen Code (Kotlin/Native, iOS). Dieses Dokument behandelt nur Kotlin auf der JVM;
    • seit Version 2.0 erscheint etwa alle sechs Monate eine neue Sprachversion (2.1.0, 2.2.0, 2.3.0, 2.4.0 …); dazwischen bringt eine Tooling-Version (2.x.20) Verbesserungen an den Werkzeugen und der Standardbibliothek, ohne die Sprache zu ändern. Dieses Dokument verwendet die im September 2026 veröffentlichte Version 2.4.20. Neue Funktionen werden oft zunächst als experimentell eingeführt; sie müssen dann ausdrücklich aktiviert werden (über eine Compiler-Option oder die Annotation [@OptIn]), bevor sie in einer späteren Version stabil werden.

    1.2. Inhalt des Dokuments

    Das Dokument umfasst die folgenden Kapitel:

    • Kapitel 2: Einrichtung der Entwicklungsumgebung (JDK 25, IntelliJ IDEA, der Compiler [kotlinc], Gradle);
    • Kapitel 3: Grundlagen der Sprache (Typen, Null-Sicherheit, Operatoren, [if] und [when], Schleifen, Ausnahmen, Enumerationen, Funktionsparameter);
    • Kapitel 4: Klassen, Properties, Vererbung, versiegelte Klassen, Operatorüberladung, Schnittstellen, Generics, Datenklassen, Erweiterungsfunktionen;
    • Kapitel 5: Häufig verwendete Kotlin-Klassen: Zeichenketten, Arrays, Collections, Sequenzen, Text- und Binärdateien, JSON mit Jackson, reguläre Ausdrücke;
    • Kapitel 6: Geschichtete Architekturen, Unit-Tests mit JUnit 6 und Dependency Injection mit Spring;
    • Kapitel 7: Funktionale Typen, Lambda-Ausdrücke und Ereignisse;
    • Kapitel 8: Ausführungs-Threads, Synchronisierung und virtuelle Threads;
    • Kapitel 9: Asynchrone Programmierung mit Coroutinen;
    • Kapitel 10: Datenbankzugriff mit JDBC;
    • Kapitel 11: Hibernate;
    • Kapitel 12: Webprogrammierung (TCP/IP, TCP-Clients und -Server, HTTP mit [HttpClient], SMTP);
    • Kapitel 13: Webservices mit Spring Boot;
    • Kapitel 14: Weiterführendes;
    • Anhänge: Installation von Laragon und MySQL, von Gradle-Projekten verwendete Abhängigkeiten.

    1.3. Der rote Faden: die Steuerberechnung

    Jedes kleine Programm ist eine Kotlin-Datei, die in einem Paket mit seinem Namen abgelegt ist ([src/main/kotlin/basics04/Basics04.kt], package [basics04]). Sie können es in IntelliJ IDEA ausführen, indem Sie auf das grüne Dreieck neben seiner Funktion [main] klicken, oder auf der Kommandozeile mit Gradle ([gradlew -q run -Pmain=basics04.Basics04Kt], Kapitel 2). Programme, die eine externe Bibliothek benötigen (Jackson, JUnit, Spring, der MySQL-Treiber, Hibernate, Spring Boot), müssen diese in der Datei [build.gradle.kts] ihres Projekts deklarieren: Gradle lädt sie beim ersten Build aus dem Repository Maven Central herunter.

    Alle Programme in diesem Dokument wurden vom Kotlin-2.4.20-Compiler ohne Fehler oder Warnungen kompiliert, und zwar mit der Option, die alle Warnungen als Fehler behandelt ([allWarningsAsErrors]), und anschließend auf JDK 25 ausgeführt. Die in diesem Dokument abgedruckten Ergebnisse stammen aus diesen Ausführungen. Die der Kapitel 2 bis 4 wurden mit französischen Sprach- und Ländereinstellungen (fr-FR) erzeugt, wie auf einem französischen Windows-Rechner: Formatierte Gleitkommazahlen werden mit Dezimalkomma angezeigt, und Datumsangaben sind französisch; die der folgenden Kapitel wurden mit englischen Einstellungen erzeugt. Zwei Hinweise:

    • Fehlermeldungen des Kotlin-Compilers und des JDK (Ausnahmemeldungen) sind auf Englisch: Es gibt keine französische Übersetzung dafür;
    • die Beispiele wurden unter Linux ausgeführt. Größtenteils macht das keinen Unterschied: Kotlin auf der JVM ist plattformübergreifend. Die wenigen Unterschiede (Dateipfade mit / statt \, Terminalbefehle, [./gradlew] statt [gradlew]) werden an den betreffenden Stellen vermerkt.

    Die Ergebnisse von Multithreading-, asynchronen oder Netzwerkprogrammen sowie die gemessenen Zeiten können von Lauf zu Lauf variieren: Die Kommentare konzentrieren sich auf das Reproduzierbare.
